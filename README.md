# Trámite Fácil España

es una pagina de gestoria de documento para tratmitarle a la gente la ciudadania española, quiero crear la pagina como en la imagen respetando los colores principales (azul diplomatico, beige, blanco y negro), que tengo un menu con los tipos de tramite, que tenga un boton para instagram y para el correo, que el usuario tenga que enviar un formulario con nombre, apellido, mail, numero telefonico y tipo de tramite y que se envien esos formularios a un correo de la empresa. Tambien quiero que sea responsive para celular
